SHORTS Yayin – Gizlilik Politikası

Son güncelleme: 14 Kasım 2026

SHORTS Yayin, Mimar Fırat Özgen'in kendi YouTube kanallarını (Mimar Fırat Özgen, Arch. Fırat Özgen, المعماري فرات أوزغن) yönetmek için kullandığı kişisel bir araçtır. Uygulama genel kullanıma açık değildir; yalnızca kanal sahibinin kendi Google hesabıyla kullanılır.

Hangi verilere erişilir

Uygulama, kanal sahibinin izniyle YouTube Data API ve YouTube Analytics API üzerinden şu işlemleri yapar: video yükleme, video başlığı, açıklaması, kapağı ve oynatma listelerini düzenleme, kanal bilgilerini güncelleme ve kanal istatistiklerini okuma.

Veriler nasıl saklanır

Erişim anahtarları (token) yalnızca kanal sahibinin kendi bilgisayarında saklanır. Hiçbir veri üçüncü kişilerle paylaşılmaz, satılmaz, reklam amacıyla kullanılmaz ve başka bir sunucuya gönderilmez.

Google API Hizmetleri

SHORTS Yayin'in Google API'lerinden aldığı bilgilerin kullanımı, Sınırlı Kullanım (Limited Use) şartları dahil olmak üzere Google API Hizmetleri Kullanıcı Verileri Politikası'na uygundur. Uygulama ayrıca YouTube Hizmet Şartları'nı kullanır; Google Gizlilik Politikası geçerlidir.

Erişimi kaldırma

Verilen izin her an Google Hesabı → Üçüncü taraf erişimi sayfasından geri alınabilir.

SHORTS Yayin – Privacy Policy

Last updated: 14 November 2026

SHORTS Yayin is a personal tool used by architect Fırat Özgen to manage his own YouTube channels (Mimar Fırat Özgen, Arch. Fırat Özgen, المعماري فرات أوزغن). The app is not offered to the public; it is used only with the channel owner's own Google account.

Data accessed

With the channel owner's permission, the app uses the YouTube Data API and YouTube Analytics API to upload videos, edit video titles, descriptions, thumbnails and playlists, update channel information, and read channel statistics.

How data is stored

Access tokens are stored only on the channel owner's own computer. No data is shared with third parties, sold, used for advertising, or sent to any other server.

Google API Services

SHORTS Yayin's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account → Third-party access.
